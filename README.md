## 🛠️ Tech Stack & Implementation Details

* **Core:** Semantic HTML5, Modular CSS3 (Custom Variables, CSS Grid, Fluid Typography, Micro-interactions), Vanilla ES6+ JavaScript.
* **Libraries:** Lucide Icons (`lucide.min.js`), Three.js (`three.min.js`), Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*).
* **Performance:** Fixed 60 FPS compositor transforms (`translate3d`), zero-layout-shift design, 100/100 Core Web Vitals targets.
* **Accessibility:** WCAG 2.1 compliance, `prefers-reduced-motion` fallbacks, keyboard navigable dialogs and focus styles.

## 🚀 Running Locally

### Prerequisites
* Node.js (v18+ recommended)
* npm (v9+ recommended)

### Setup & Launch
```bash
# Clone the repository
git clone https://github.com/sathiyaraj16/sathiyaraj_portfolio_.git

# Navigate to project directory
cd sathiyaraj_portfolio_

# Install local dependencies
npm install

# Start local development server
npm run dev
```

Server active at: **[http://localhost:3000](http://localhost:3000)**

## 🛡️ Git Branching & Contribution Workflow

This project adheres to a safe Git branching workflow:
1. `main` is production-ready and protected against unverified direct modifications.
2. New features and UI updates are developed on dedicated feature branches (e.g. `feature/portfolio-update`).
3. Changes are thoroughly tested locally (build verification, responsive layouts, console checks) before merging into `main`.
